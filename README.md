# NFC RS — بطاقات أعمال ذكية بتقنية NFC

منصة كاملة لبيع بطاقات NFC:
- الزبون **يلمس بطاقته** أول مرة ← ينشئ حسابه (جوجل أو بريد) ← يصمم صفحة روابطه.
- أي شخص يلمس البطاقة بعد ذلك تفتح له **صفحة صاحبها**، ويحفظ رقمه بزر واحد.
- أنت (المدير) تنشئ البطاقات، تبرمجها، تطبع رموز QR، وتتابع التفعيل.

مبني بـ **React + Vite**، ويستعمل **Firebase** (الحسابات وقاعدة البيانات) ويُنشر على **GitHub Pages** تلقائياً.

---

## الصفحات

| الملف | من يراه | الوظيفة |
|---|---|---|
| `index.html` | الجميع | الصفحة الرئيسية، صفحة كل زبون `?u=الاسم`، شاشة البطاقة `?c=الرمز` |
| `login.html` | الجميع | تسجيل الدخول / إنشاء حساب / نسيت كلمة المرور |
| `app.html` | الزبون | لوحة التحكم: الصورة، الروابط، 8 تصاميم، QR، NFC، الإحصائيات، بطاقاتي |
| `admin.html` | المدير فقط | إنشاء البطاقات، متابعتها، كتابة NFC، طباعة QR، تصدير CSV |

## هيكل الكود

```
src/
  pages/        Home, Login, Dashboard, Admin   ← كل صفحة
  components/   ProfileView (صفحة الزبون العامة)، ui (أيقونات، شعار، بطاقة، هاتف، إشعارات)
  lib/          db.js (Firebase)، utils.js (المنصات، التصاميم، QR، NFC)، icons.js، firebase-config.js
  entries/      نقطة تشغيل كل صفحة
  styles.css    التصميم (أسود وذهبي)
firestore.rules قواعد الحماية — تُلصق في Firebase
```

## النشر (مرة واحدة)

1. في GitHub: **Settings → Pages → Build and deployment → Source** ← اختر **GitHub Actions**.
2. كل دمج في `main` يبني الموقع وينشره تلقائياً (ملف `.github/workflows/deploy.yml`).
   تتابع التقدم في تبويب **Actions**.

## Firebase (تم إعداده لمشروع NFC RS)

- إعدادات الربط في `src/lib/firebase-config.js`.
- قواعد الحماية في `firestore.rules` — إذا عدّلتها، الصقها من جديد في
  Firebase ← Firestore Database ← **Règles** ← **Publier**.
- **إضافة مدير:** Firestore ← Données ← مجموعة `admins` (في المستوى الأول، بجانب `profiles`)
  ← مستند اسمه **معرّف الحساب** (يظهر في `admin.html`) ← حقل `role` = `owner`.

## بيع البطاقات

1. `admin.html` ← اكتب العدد ← **إنشاء** (كل بطاقة تأخذ رمزاً فريداً).
2. **أندرويد (Chrome):** زر **NFC** بجانب البطاقة ← قرّب البطاقة من ظهر الهاتف.
   **آيفون:** زر **نسخ** ← تطبيق NFC Tools ← Write ← URL.
3. **طباعة QR** ← الصق رمز كل بطاقة على نفس البطاقة.
4. استعمل بطاقات **NTAG213 / NTAG215** (تعمل مع آيفون وأندرويد)، ولا تقفلها (Lock) أبداً.

> عند ربط نطاق خاص لاحقاً، تُعاد كتابة البطاقات بالرابط الجديد — لذلك لا تبِع بطاقات قبل ربط النطاق.

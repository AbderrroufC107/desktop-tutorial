# My Link — صفحة روابط شخصية تعمل مع NFC

موقع بسيط مثل My Link / Linktree: صفحة واحدة فيها كل حساباتك (واتساب، إنستغرام، تيك توك…)،
وزر لحفظ جهة الاتصال، مع محرر يولّد الرابط ورمز QR ويكتب الرابط مباشرة على بطاقة NFC.

لا يحتاج سيرفر ولا قاعدة بيانات — يعمل على **GitHub Pages** مجاناً.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | صفحة الملف الشخصي التي يراها الناس عند لمس البطاقة |
| `edit.html` | المحرر: تعديل البيانات، معاينة مباشرة، QR، كتابة NFC |
| `profiles/me.json` | بياناتك (الصفحة الافتراضية) |
| `profiles/<اسم>.json` | صفحات أشخاص آخرين: `index.html?u=<اسم>` |
| `assets/` | التصميم والكود المشترك |

## التشغيل على GitHub Pages

1. في المستودع على GitHub: **Settings → Pages**.
2. في **Source** اختر `Deploy from a branch`، ثم الفرع والمجلد `/ (root)`، واضغط Save.
3. بعد دقيقة يصبح الموقع على:
   `https://<اسم-حسابك>.github.io/desktop-tutorial/`

## الاستعمال

1. افتح `edit.html` على موقعك واملأ اسمك وروابطك (تظهر المعاينة مباشرة).
2. اختر **رابط قصير** واكتب اسم مستخدم، مثلاً `abderraouf`.
3. اضغط **تحميل ملف JSON** وارفع الملف إلى مجلد `profiles/` في المستودع
   (أو عدّل `profiles/me.json` مباشرة إذا كانت الصفحة لك وحدك).
4. صفحتك الآن على: `https://<حسابك>.github.io/desktop-tutorial/?u=abderraouf`

> **رابط يحتوي البيانات:** خيار ثانٍ يضع كل بياناتك داخل الرابط نفسه، فلا تحتاج لرفع أي ملف.
> لكنه طويل، وغالباً لا يتسع في بطاقات NFC الصغيرة، كما أن تغيير بياناتك يغيّر الرابط.
> لذلك الرابط القصير أفضل للبطاقات: تعدّل الملف متى شئت والبطاقة تبقى كما هي.

## الكتابة على بطاقة NFC

**الطريقة 1 — من المحرر مباشرة (Chrome على أندرويد):**
افتح `edit.html` من موقعك (يجب أن يكون HTTPS)، اضغط **كتابة الرابط على بطاقة NFC**، وقرّب البطاقة من ظهر الهاتف.

**الطريقة 2 — آيفون أو أي هاتف:**
اضغط **نسخ الرابط**، ثم افتح تطبيق **NFC Tools** → Write → Add a record → URL → الصق الرابط → Write وقرّب البطاقة.

**نوع البطاقة:** NTAG213 تكفي للرابط القصير، وNTAG215/216 تعطي مساحة أكبر. المحرر يعرض حجم الرابط وأي بطاقة تناسبه.

**نصائح:**
- اطبع رمز QR من المحرر على البطاقة أيضاً للهواتف التي لا تدعم NFC.
- لا تقفل البطاقة (Lock) إلا إذا كنت متأكداً — القفل نهائي. مع الرابط القصير لن تحتاج لإعادة الكتابة أصلاً.

## التجربة محلياً

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000/edit.html
```

(كتابة NFC من المتصفح تحتاج HTTPS، لذلك جرّبها على GitHub Pages.)

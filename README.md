# My Link — منصة صفحات روابط مع بطاقات NFC

منصة مثل My Link / Linktree:
- أي شخص **ينشئ حساباً** (بجوجل أو بالبريد) ويصمم صفحة روابطه.
- أنت (صاحب الموقع) **تبيع بطاقات NFC**، لكل بطاقة رمز فريد.
- المشتري يلمس البطاقة أول مرة ← ينشئ حسابه ← تصبح البطاقة له، وكل من يلمسها بعد ذلك تفتح له صفحة صاحبها.

يعمل على **GitHub Pages** مجاناً، ويستعمل **Firebase** (مجاني) للحسابات وقاعدة البيانات.

---

## كيف تعمل عملية البيع

```
أنت (لوحة البطاقات)                    الزبون
──────────────────                    ──────
1. تنشئ 50 بطاقة → 50 رمزاً فريداً
2. تكتب رابط كل بطاقة على شريحة NFC
   وتطبع رمز QR عليها
3. تبيع البطاقة  ───────────────────►  4. يلمس البطاقة بهاتفه
                                       5. تظهر له "بطاقة جديدة! فعّلها"
                                       6. ينشئ حساباً (جوجل أو بريد)
                                       7. يختار اسماً ويضيف روابطه
                                       8. البطاقة الآن مربوطة بحسابه
                                       
   أي شخص يلمس البطاقة بعد ذلك  ──►  تفتح صفحة الزبون مباشرة
```

- الزبون يعدّل صفحته متى شاء من لوحة التحكم، والبطاقة لا تحتاج إعادة كتابة.
- يرى الزبون عدد زيارات صفحته وعدد لمسات بطاقته.
- إذا ضاعت البطاقة يستطيع "فصلها" من حسابه.

## الصفحات

| الصفحة | لمن | الوظيفة |
|---|---|---|
| `index.html` | الجميع | الصفحة الرئيسية، وصفحات المستخدمين `?u=الاسم`، والبطاقات `?c=الرمز` |
| `login.html` | الجميع | تسجيل الدخول وإنشاء حساب (جوجل أو بريد) ونسيت كلمة المرور |
| `app.html` | المستخدم | لوحة التحكم: تعديل الصفحة، الصورة، الروابط، QR، NFC، بطاقاتي، الإحصائيات |
| `admin.html` | أنت فقط | إنشاء البطاقات، متابعتها، طباعة رموز QR، كتابة NFC، تصدير CSV |

## الإعداد (مرة واحدة فقط — حوالي 10 دقائق)

### 1. أنشئ مشروع Firebase
1. افتح https://console.firebase.google.com وسجّل بحساب جوجل.
2. اضغط **Create a project** (أو Add project)، سمّه مثلاً `mylink`، وأكمل الخطوات (Google Analytics غير ضروري).

### 2. فعّل تسجيل الدخول
1. من القائمة: **Build → Authentication → Get started**.
2. في تبويب **Sign-in method** فعّل:
   - **Google** (اختر بريد الدعم ثم Save)
   - **Email/Password** (فعّل الخيار الأول ثم Save)
3. في تبويب **Settings → Authorized domains** اضغط **Add domain** وأضف:
   `abderrroufc107.github.io`

### 3. أنشئ قاعدة البيانات
1. من القائمة: **Build → Firestore Database → Create database**.
2. اختر موقعاً قريباً (مثلاً `europe-west`) ثم **Start in production mode**.
3. افتح تبويب **Rules**، احذف كل ما فيه، والصق محتوى ملف [`firestore.rules`](firestore.rules) ثم **Publish**.

### 4. اربط الموقع بـ Firebase
1. من ⚙️ **Project settings** → في الأسفل **Your apps** → اضغط أيقونة الويب `</>`.
2. سمّ التطبيق `mylink` واضغط **Register app**.
3. سيظهر لك كود فيه `firebaseConfig`. انسخ القيم وضعها في ملف
   [`assets/firebase-config.js`](assets/firebase-config.js) في المستودع، مثلاً:
   ```js
   export const firebaseConfig = {
     apiKey: 'AIzaSy...',
     authDomain: 'mylink-xxxx.firebaseapp.com',
     projectId: 'mylink-xxxx',
     storageBucket: 'mylink-xxxx.appspot.com',
     messagingSenderId: '1234567890',
     appId: '1:1234567890:web:abcdef'
   };
   ```
   (هذه القيم ليست سرية — الحماية تأتي من قواعد `firestore.rules`.)
   يمكنك تعديل الملف مباشرة من GitHub: افتحه ← أيقونة القلم ✏️ ← الصق ← **Commit changes**.

### 5. اجعل نفسك المدير
1. افتح موقعك وأنشئ حسابك: `https://abderrroufc107.github.io/desktop-tutorial/login.html`
2. افتح `admin.html` — ستظهر رسالة فيها **معرّف حسابك (uid)**، انسخه.
3. في Firebase: **Firestore Database → Data → Start collection**:
   - Collection ID: `admins`
   - Document ID: الصق الـ uid
   - أضف أي حقل، مثلاً `name` = `owner`، ثم Save.
4. حدّث صفحة `admin.html` — أصبحت لوحة البطاقات تعمل لك.

## تجهيز البطاقات للبيع

1. افتح `admin.html`، اكتب العدد (مثلاً 20) واضغط **إنشاء**.
2. لكل بطاقة:
   - **على أندرويد (Chrome):** اضغط زر **NFC** بجانب البطاقة وقرّب الشريحة من الهاتف.
   - **على آيفون أو غيره:** اضغط **نسخ** ثم اكتب الرابط بتطبيق **NFC Tools** (Write → Add a record → URL).
3. اضغط **طباعة رموز QR** لطباعة ورقة فيها رمز QR لكل بطاقة مع رمزها — للهواتف التي لا تدعم NFC.
4. **تصدير CSV** يعطيك جدولاً بكل البطاقات وروابطها وحالتها.

**نوع الشريحة:** رابط البطاقة قصير (حوالي 50 حرفاً)، فـ **NTAG213** تكفي وهي الأرخص.

> 💡 لا تقفل الشرائح (Lock) — لا حاجة لذلك، فالرابط ثابت والتعديل يتم في الحساب.

## ملاحظات
- **صورة الملف الشخصي** تُصغَّر تلقائياً وتُحفظ في قاعدة البيانات (لا حاجة لـ Firebase Storage المدفوع).
- **الخطة المجانية** لـ Firebase تكفي لآلاف المستخدمين (50 ألف قراءة يومياً).
- **أسماء محجوزة** لا يمكن للمستخدمين أخذها: `admin`, `login`, `app`, … (في `assets/db.js`).
- **نطاق خاص:** يمكنك لاحقاً ربط نطاق مثل `mylink.dz` من إعدادات GitHub Pages (ثم أضفه في Authorized domains في Firebase). انتبه: تغيير النطاق يغيّر روابط البطاقات المكتوبة سابقاً، فقرّر النطاق قبل كتابة البطاقات.
